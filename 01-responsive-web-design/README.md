# Responsive Web Design Projects

A collection of 15 projects built while learning responsive web design with HTML and CSS. The projects progress from CSS illustrations and animations to responsive layouts, accessible components, and reusable design systems.

## Getting Started

Each project is self-contained. Open its `index.html` file in a browser to view it; no build step or package installation is required.

For example, open `01-barad-dur/index.html` to view the first project. Resize the browser window to explore responsive behavior where applicable.

## Skills Practised

- Semantic HTML and accessible form structures
- CSS Flexbox and Grid for responsive layouts
- Mobile-first styling and media queries
- CSS custom properties and design tokens
- Gradients, transforms, transitions, and keyframe animations
- Keyboard focus states, reduced-motion preferences, and assistive-technology semantics

Each project directory contains its own README with more detail about its implementation, learning goals, and known limitations.
