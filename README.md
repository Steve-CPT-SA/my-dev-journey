# My Dev Journey

## About

This repository documents my transition from a 12-year career as an electrician into software development.

It serves as a central hub for the projects, experiments, and learning milestones completed while building skills in web development, programming, and AI technologies.

Many of the projects began as learning exercises but were redesigned, expanded, or rebuilt to reinforce concepts through practical application and creative problem-solving.
