# Household Utility Calculator Suite

A web-based calculator suite built with HTML, CSS, and JavaScript to help users calculate energy consumption, estimate electricity costs, compare appliance usage, and perform everyday arithmetic calculations.

## Features

### Basic Calculator
- Addition, subtraction, multiplication, and division
- Operator precedence support
- Decimal support
- Input validation
- Error handling for division by zero
- Clear and delete functionality

### Energy Calculator
- Calculates energy consumption in kWh
- Formula display
- Input validation
- Reset functionality

Formula:

E(kWh) = Power(W) × Time(h) ÷ 1000

### Electricity Cost Estimator
- Estimates electricity costs from energy consumption
- Currency code validation
- Cost formatting
- Reset functionality

Formula:

Cost = Consumption(kWh) × Rate

### Appliance Comparison
- Compares the energy consumption of two appliances
- Indicates which appliance consumes more energy
- Supports equal energy consumption comparisons
- Reset functionality

Formula:

Energy (kWh) = Power(W) × Time(h) ÷ 1000

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No installation or build tools are required.
